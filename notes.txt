At prompt:
    Ctrl-C  -> new prompt, exit code 130
    Ctrl-\  -> ignored
    Ctrl-D  -> exit

During heredoc:
    Ctrl-C  -> stop heredoc, do not execute command, exit code 130
    Ctrl-\  -> ignored

During execution:
    Ctrl-C  -> kill child command, shell survives, exit code 130
    Ctrl-\  -> quit child command, shell survives, exit code 131

1. Prompt mode
2. Heredoc mode
3. Parent execution mode
4. Child execution mode

Prompt mode:
    shell handles Ctrl-C itself

Heredoc mode:
    shell cancels heredoc on Ctrl-C

Parent execution mode:
    parent ignores Ctrl-C / Ctrl-\ while child is running

Child execution mode:
    child uses default signal behavior

-----------------------------------------------------------------
Before prompt readline:
    call set_signal_prompt()

Before heredoc:
    call set_signal_heredoc()
    if Ctrl-C happens, heredoc returns fail and command must not execute

Before parent waits:
    call set_signal_exec_parent()

Inside every child after fork:
    call set_signal_exec_child()

After wait:
    calculate exit code:
        WIFEXITED -> WEXITSTATUS
        WIFSIGNALED -> 128 + WTERMSIG
    then call set_signal_prompt()
